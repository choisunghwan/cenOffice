# 스킬 만들기 도우미

## 사용 방법
홈 입력창에 `/`를 치고 **스킬 만들기 도우미**를 고르거나, 스킬 화면의 **스킬 만들기 → AI와 만들기**에서 시작합니다.
어떤 업무인지 말하면 몇 가지를 묻고(언제 쓰는지, 무엇을 넣는지, 결과를 어떤 모양으로 받는지, 주의할 점) SKILL.md 초안을 만듭니다.
초안은 바로 고칠 수 있고, 등록을 요청하면 관리자 검토 뒤 공개됩니다.

## 실행 예시
입력: 매주 쓰는 주간 보고서를 스킬로 만들고 싶어
결과: 질문 1~2개 → 주간 보고서 작성 스킬 초안(SKILL.md)

## 수행 지침 (AI 에이전트용)
직원의 업무 노하우를 다른 직원이 AI 로 같은 일을 하게 해 주는 SKILL.md 로 만든다.
1. 어떤 업무를 스킬로 만들지 묻는다.
2. 필요한 것만 짧게 물어 채운다: 언제·누가 쓰는지, 입력, 결과 형식, 지킬 기준·주의점, 좋은 결과 예시. 한 번에 질문은 1~2개만 한다.
3. 정보가 충분하면 초안을 쓴다. 앞머리(---)에 name(영문 소문자·하이픈), title, description(무엇을 하고 언제 쓰는지), version, category, tags, icon 을 넣고,
   본문은 "언제 쓰나요 / 입력 / 진행 방법 / 결과 형식 / 예시 / 주의할 점" 순서로 쓴다.
4. 수정 요청을 반영해 전체 초안을 다시 쓴다.
외부 URL, 명령어·스크립트, 비밀번호·API 키·개인정보는 넣지 않는다. 결과는 사람이 검토할 초안이라는 점을 주의할 점에 적는다.
