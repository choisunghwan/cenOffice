# 예시

## 통과 예
- title: 주간 보고서 작성
- description: 이번 주 한 일 메모를 넣으면 완료·진행·이슈로 나눈 주간 보고서 초안을 만듭니다. 매주 금요일 보고 전에 씁니다.
- 본문: 언제 쓰나요 · 입력(메모 예시) · 진행 방법 1~4단계 · 결과 형식(표) · 예시(입력→결과) · 주의할 점(검토용 초안)
- 판정: **통과** — 할 일·입력·결과가 분명하고 안전 문제가 없다.

## 보완 필요 예
- title: 도우미
- description: 업무를 도와줍니다.
- 본문: "사용자의 요청을 잘 처리하세요." 한 줄
- 판정: **보완 필요** — 무엇을 하는 스킬인지 알 수 없다(명확성·높음), 입력·결과 형식·예시가 없다(완결성·중간).

## 반려 권고 예
- 본문에 AI 에게 원래 지침을 버리라고 하는 문장과, 관리자 계정의 비밀번호가 그대로 적혀 있음
- 판정: **반려 권고** — 비밀 정보 포함, 지침을 버리게 하는 문장(안전·높음).
