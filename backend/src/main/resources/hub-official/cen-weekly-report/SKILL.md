# 주간 업무보고 작성

## 언제 쓰나요
- 매주 팀장·PM 보고 전에, 흩어진 메모를 보고서 형식으로 정리할 때
- 여러 프로젝트를 동시에 하고 있어 한눈에 보이는 요약이 필요할 때

## 입력
- 이번 주 한 일, 진행 중인 일, 다음 주 할 일, 문제·도움이 필요한 일을 자유롭게 적은 메모
- [완료]·[진행] 같은 구분 표시는 없어도 된다. 진행률(%)·날짜·담당자가 있으면 그대로 살린다.
- 선택: 프로젝트 이름, 보고 대상(팀장·고객 등)

## 진행 방법
1. `references/report-structure.md` 의 구분(완료 · 진행 중 · 다음 주 예정 · 이슈·리스크 · 협조 요청)으로 메모를 나눈다.
2. `references/writing-rules.md` 의 작성 원칙으로 문장을 다듬는다(결과 중심, 숫자 살리기, 지어내지 않기).
3. 결과는 `templates/report.md` 형식으로 쓴다. 예시는 `examples/` 폴더를 참고한다.
4. 메모에서 빠진 정보(진행률, 이슈의 담당·기한 등)는 채우지 말고 "보완 필요"에 모아 알린다.

## 파일 구성
- `references/report-structure.md` — 보고서 구분과 각 구분에 들어갈 내용
- `references/writing-rules.md` — 문장 작성 원칙과 하지 말아야 할 것
- `templates/report.md` — 결과 형식
- `examples/free-memo.md` — 자유 메모 → 보고서 예시

## 주의할 점
- 메모에 없는 일·숫자·날짜를 만들어 넣지 않는다. 결과는 사람이 검토할 초안이다.
- 고객사 이름·개인정보 등 민감 정보가 보이면 그대로 옮기되, 보고 대상에 맞는지 확인하라고 알린다.
