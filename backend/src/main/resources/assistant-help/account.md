# 로그인·알림·설정
질문: 로그인이나 알림 설정은 어디서 해요?
키워드: 로그인, 아이디 저장, 비밀번호, 알림, 설정, 사용법 다시 보기, 안내, 투어, 로그아웃, 계정, 메일

- 로그인 화면의 "아이디 저장"을 체크하면 다음에 아이디가 미리 채워집니다(비밀번호는 저장하지 않습니다). 탭이나 브라우저를 닫으면 로그아웃됩니다.
- 오른쪽 위 종 모양에서 알림(회의록 확정, 할 일 지정, 일정 초대)을 봅니다. 메일 알림은 설정에서 받을지 정합니다.
- 오른쪽 위 달 모양 버튼으로 다크 모드를 바꿀 수 있습니다.
- 처음 로그인하면 사용법 안내(화면이 어두워지며 주요 기능을 짚어 줌)가 나옵니다. 설정 화면의 "사용법 다시 보기"로 언제든 다시 볼 수 있습니다.
