# 회의록 만들기와 확정
질문: 회의록은 어떻게 만들고 확정해요?
키워드: 회의록, 요약, 확정, 초안, 진행자, 액션 아이템, 할 일, 담당자, 알림, 삭제

1. 회의가 끝나면 진행자가 "회의록 만들기"를 누릅니다. 회의 채팅과 음성 기록, 진행자가 적은 메모를 합쳐 요약합니다(AI가 연결되어 있으면 AI, 아니면 규칙 방식).
2. 요약은 항상 같은 틀로 나옵니다: 요약, 결정 사항, 액션 아이템(담당자·기한), 이슈.
3. 진행자가 내용을 고치고 담당자를 지정한 뒤 "확정하고 참석자에게 알리기"를 누릅니다. 확정하면 더 이상 수정할 수 없습니다.
4. 확정하면 참석자에게 알림이 가고, 담당자로 지정된 사람은 내 할 일에 추가됩니다. 설정에 따라 메일 알림도 갑니다.
- 확정 전 초안은 진행자만 볼 수 있습니다.
- 회의록을 삭제하는 기능은 아직 없습니다.
