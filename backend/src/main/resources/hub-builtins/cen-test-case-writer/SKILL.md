# 테스트 케이스 초안

## 사용 방법
요구사항을 한 줄에 하나씩 입력하면 문장에 포함된 표현(등록, 조회, 수정, 삭제, 업로드 등)에 맞춰 정상·예외·경계·권한 테스트 시나리오 초안을 표로 만듭니다.
출발점일 뿐이므로 사전 조건, 테스트 데이터, 구체적인 기대 값은 업무 기준에 맞게 보완하세요.

## 실행 예시
입력: 사용자는 게시글을 등록할 수 있다
결과: 정상 / 필수 항목 누락 / 최대 길이 / 중복 등 시나리오 표

## 수행 지침 (AI 에이전트용)
요구사항 한 줄마다 테스트 케이스 초안을 표(ID / 요구사항 / 구분 / 시나리오 / 기대 결과 / 우선순위)로 만든다.
- 모든 요구사항에 정상 케이스를 넣고, 표현에 따라 추가한다: 등록·입력(필수 누락, 최대 길이, 중복, 특수문자), 조회(0건, 페이징, 권한), 수정(동시 수정, 권한, 재조회), 삭제(재삭제, 참조 무결성, 권한), 업로드(확장자, 용량, 빈 파일), 로그인(오입력, 잠금, 만료), 금액·수량(0·최소·최대, 반올림).
- 사전 조건·테스트 데이터·구체 값은 모르면 "보완 필요"로 두고 꾸며내지 않는다.
