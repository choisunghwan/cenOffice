# 도구 찾기·쓰기·만들기
질문: 도구는 어떻게 찾고 만들어요?
키워드: 도구, 스킬, 툴, 찾기, 쓰기, 만들기, 등록, 공유, 내 도구, 승인, 공개, 인기순, 정렬

- 도구 화면에서 승인된 도구를 검색하고 카테고리·정렬(최신순/인기순)로 고릅니다. 상단의 "내 도구", "도구 만들기" 버튼으로 이동합니다.
- 도구 상세의 "사용하기" 탭에서 내용을 넣고 실행합니다. 결과는 복사하거나 한글·워드·엑셀·파워포인트·PDF 파일로 받을 수 있고, 양식이 올려져 있으면 그 양식에 채워 받을 수 있습니다.
- 도구 만들기: SKILL.md 파일(또는 ZIP)을 올리거나 직접 작성해 등록합니다. 결과물 양식은 등록할 때 함께 올려도 됩니다. 전사에 공개하려면 관리자 승인을 거칩니다.
- 도구 수정(양식 올리기, 보관 등)은 만든 사람과 관리자만 할 수 있습니다.
- 홈 입력창에서 "쓸만한 도구 뭐 있어?"라고 물으면 많이 쓴 순서로 알려 주고, 업무 내용을 말하면 맞는 도구를 골라 줍니다.
