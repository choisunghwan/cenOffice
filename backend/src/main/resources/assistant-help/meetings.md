# 화상 회의
질문: 회의는 어떻게 시작하고 참여해요?
키워드: 회의, 화상, 미팅, 시작, 참여, 참여 코드, 입장, 마이크, 카메라, 음성 기록, 채팅

- 회의 화면에서 회의를 만들면 참여 코드가 생깁니다. 코드를 동료에게 보내면 그 코드로 입장합니다.
- 입장 전에 "마이크 켜고 참여", "카메라 켜고 참여"를 고를 수 있고, 참여한 뒤에도 바꿀 수 있습니다.
- 회의 중에는 회의 채팅을 쓸 수 있고, 참석자가 동의하면 음성이 글자로 기록됩니다(오디오는 저장하지 않고 글자만 저장).
- 한 PC에서 브라우저를 두 개 쓸 때는 한쪽 마이크를 꺼야 소리가 울리지 않습니다.
- 회의 목록은 제목으로 검색하고 페이지로 넘겨 볼 수 있습니다.
- 홈 입력창에서 "회의 시작해줘", "회의 열어줘"나 참여 코드를 붙여 "참여해줘"라고 해도 됩니다.
