# 작성 원칙

- **결과 중심**: "~함"보다 "무엇이 어떻게 됐는지"를 쓴다. (예: "로그인 개선" → "로그인 속도 개선, 3초 → 1초")
- **숫자는 살린다**: 메모에 있는 건수·%·시간·날짜는 빠뜨리지 않는다.
- **짧게**: 한 항목은 한 줄, 길어도 두 줄.
- **보고 말투**: 명사형 종결("~완료", "~진행 중")로 통일한다.
- **지어내지 않는다**: 메모에 없는 결과·숫자·원인을 추측해 넣지 않는다.
- **이슈에는 다음 행동**: 담당·기한·필요한 결정이 메모에 있으면 붙이고, 없으면 "보완 필요"에 적는다.
