# 일정과 회의실 예약
질문: 일정은 어떻게 등록해요?
키워드: 일정, 캘린더, 달력, 예약, 회의실, 등록, 삭제, 변경, 전체 일정, 개인 일정, 월, 주

- 일정 화면에서 월/주 보기를 바꾸고, "전체 일정"(회사 공통)과 "개인 일정"을 오갈 수 있습니다. 전체 일정은 관리자와 일정 관리자만 만들고 고칠 수 있습니다.
- 위쪽 "일정 만들기"로 선택한 날짜에 일정을 만듭니다. 참석자를 초대할 수 있고, 초대받은 사람에게 알림이 갑니다.
- 회의실 예약도 일정에 함께 보입니다.
- 홈 입력창에서도 됩니다: "내일 오후 3시에 팀 회의 잡아줘", "A회의실 예약해줘", "내일 회의 3시로 옮겨줘", "이번 주 일정 알려줘". 등록·삭제·변경은 확인 카드에서 한 번 더 확인합니다.
- 기한이 날짜인 내 할 일도 일정 화면에 표시됩니다.
