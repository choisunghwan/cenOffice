# 브라우저 지원 판단 원칙

- 주요 브라우저(크롬·엣지·파이어폭스·사파리)의 최신 버전에서 모두 되는 기능을 먼저 권한다.
- 일부 브라우저만 되면 "지원 범위 확인 필요"로 적고, 안 되는 브라우저에서의 대안(그대로 두기, 단순한 대체 동작)을 함께 적는다.
- 사용자가 지원 브라우저를 알려 주면(예: 사내 크롬·엣지 최신) 그 기준으로만 판단한다.
- 지원 정보는 바뀔 수 있으므로, 중요한 화면은 사내 표준 브라우저에서 직접 확인하라고 안내한다.
- 표의 "브라우저 지원" 칸은 다음 셋 중 하나로 쓴다: 모두 지원 / 대부분 지원(예외 적기) / 확인 필요
