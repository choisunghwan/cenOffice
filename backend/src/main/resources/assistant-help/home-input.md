# 홈 입력창 사용법
질문: 홈 입력창은 어떻게 써요?
키워드: 홈, 입력창, 채팅, 말로, 명령, 시키, 보내기, 중단, 예시

홈 화면 아래의 입력창에 하고 싶은 일을 평소 말투로 쓰고 Enter(줄바꿈은 Shift+Enter)로 보냅니다.
- 일정·회의실 예약·삭제·변경, 내 할 일 확인, 오늘 브리핑, 회의 시작·참여, 회의록 다운로드, 도구 쓰기, 화면 조작을 할 수 있습니다.
- 일정 등록, 삭제, 도구 실행처럼 되돌리기 어려운 일은 카드가 나오고, 확인 버튼을 눌러야 실행됩니다.
- 답을 기다리는 중에는 "중단" 버튼으로 멈출 수 있고, 멈추면 보낸 말이 입력창으로 돌아와 고쳐서 다시 보낼 수 있습니다.
- 위 목록에 없는 일반 질문은 AI가 연결되어 있을 때 대화로 답합니다.
