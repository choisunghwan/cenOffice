# FP 산정 도우미

## 사용 방법
요구사항 XLSX 또는 UTF-8 TXT/MD를 올리거나 기능 목록을 직접 입력합니다.
내장 규칙이 입력·변경, 집계·가공 출력, 단순 조회 표현을 분류합니다.
결과에는 원문, 기능 유형 후보, 확인 근거가 포함됩니다.
ILF/EIF, DET/FTR/RET 및 복잡도는 전문가가 확인해야 하며 확정 FP 합계는 제공하지 않습니다.
외부 모델로 자료를 전송하지 않습니다. 파일당 80행·12,000자 이하를 지원합니다.

## 실행 예시
입력: 고객 등록 / 월별 통계 보고 / 고객 목록 조회

| 원문 기능 | 유형 후보 | 검토 사항 |
|---|---|---|
| 고객 등록 | EI | 입력 항목 및 처리 경계 확인 |
| 월별 통계 보고 | EO | 가공·집계 로직 확인 |
| 고객 목록 조회 | EQ | 추가 가공 여부 확인 |

규칙 기반 분류 예시입니다. 확정 FP 값이 아닙니다.

## 수행 지침 (AI 에이전트용)
기능 목록을 받아 기능별 FP 유형 후보를 표로 만든다. 확정 산정이 아니라 검토용 후보임을 항상 밝힌다.
- 입력·데이터 변경 표현(등록/수정/삭제) → EI 후보, 집계·보고·계산 → EO 후보, 조회·검색 → EQ 후보, 불분명하면 "확인 필요".
- ILF/EIF, DET/FTR/RET, 복잡도가 확정되지 않았으면 FP 합계를 계산하지 않는다. 중복·복합 기능은 사람이 분리하도록 표시한다.
