# 결과물 양식 올리기와 작성 요령
질문: 양식은 어떻게 올리고, 어떻게 만들어야 채워져요?
키워드: 양식, 업로드, 올리기, 템플릿, 자리표시자, 항목, 빈 칸, 선택지, 목록 표, 한글, hwpx, docx, xlsx, pptx, 채우기

- 올리는 곳: 도구 상세 → 소개 탭의 "결과물 양식"(도구를 만든 사람과 관리자), 회의록은 회의록 화면의 "＋ 내 양식 올리기"(누구나). 한글(.hwpx)·워드(.docx)·엑셀(.xlsx)·파워포인트(.pptx) 아이콘 중 맞는 것을 누릅니다. 형식마다 하나씩 올릴 수 있습니다.
- 채워지는 자리: 본문의 {{항목}}, 표에서 "항목 이름 칸 + 오른쪽 빈 칸", 날짜 틀만 적힌 칸(예: 20 . . . ( ) : ~ :), "□ 정기 □ 임시" 같은 선택지 칸, 번호(번호·No)가 있는 목록 표(액션 아이템 등)입니다.
- 번호 칸(1, 2, 3)과 이미 값이 적힌 칸은 건드리지 않습니다.
- 항목 이름이 두 번 나오면(예: 다음 회의의 일시) 두 번째부터는 자동으로 채우지 않고 직접 입력하게 합니다.
- 한계: 항목 이름이 위, 빈 칸이 아래인 세로 배치 표는 읽지 못합니다. 값 안의 줄바꿈은 공백으로 합쳐집니다. 옛 .hwp 형식은 지원하지 않으니 한글에서 .hwpx로 저장해 올려 주세요(최대 5MB).
