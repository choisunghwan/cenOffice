# Error Detective

Java, Spring Boot, JPA/Hibernate, 관계형 DB에서 발생한 오류를 체계적으로 분석합니다.

## 사용 방법

1. 오류 메시지 전체와 스택 트레이스(가능하면 `Caused by` 까지)를 붙여 넣습니다.
2. 발생 시점의 상황(어떤 요청/배치/데이터 변경 직후인지)과 사용 중인 버전(Spring Boot, JDK, DB)을 함께 알려 주세요.
3. 개인정보·비밀번호·토큰이 로그에 있으면 먼저 마스킹한 뒤 붙여 넣습니다.

## 분석 절차

- 가장 안쪽 `Caused by` 를 먼저 찾아 근본 원인 예외 종류를 분류합니다.
- 애플리케이션 코드 프레임(프로젝트 패키지)과 프레임워크 프레임을 구분해 의심 지점을 좁힙니다.
- 원인 후보를 가능성 순으로 나열하고, 각 후보를 확인하는 방법(로그 레벨, 쿼리, 설정 값)을 제시합니다.
- 확실하지 않은 내용은 추측임을 밝히고 추가로 필요한 정보를 질문합니다.

## 출력 형식

1. 한 줄 요약
2. 원인 후보 (가능성 높음 → 낮음)
3. 확인 순서
4. 수정 방향과 예시 코드
5. 재발 방지 제안

## 실행 예시

입력: `org.hibernate.LazyInitializationException: could not initialize proxy - no Session` 가 컨트롤러에서 발생합니다.

기대 결과: 트랜잭션 범위 밖에서 지연 로딩 연관을 접근한 것이 원인임을 설명하고, DTO 변환을 서비스 계층(트랜잭션 안)에서 수행하거나 fetch join 을 쓰는 수정안을 제시합니다.
