# 예시: 로그인

## 입력
사용자는 아이디와 비밀번호로 로그인할 수 있다
비밀번호를 5회 틀리면 계정이 잠긴다
관리자만 사용자 목록 화면에 들어갈 수 있다

## 결과
**요약**: 요구사항 3개 → 테스트 케이스 8건 (상 6 · 중 2)

| ID | 요구사항 | 구분 | 사전 조건 | 절차 | 입력 데이터 | 기대 결과 | 우선순위 |
|---|---|---|---|---|---|---|---|
| TC-001 | 로그인 | 정상 | 가입된 계정 | 1. 아이디·비밀번호 입력 2. 로그인 | test01 / P@ssw0rd! | 홈 화면으로 이동 | 상 |
| TC-002 | 로그인 | 예외 | 가입된 계정 | 틀린 비밀번호로 로그인 | test01 / wrong | 오류 안내, 로그인 안 됨 | 상 |
| TC-003 | 로그인 | 필수·형식 | – | 아이디 빈 칸으로 로그인 | (빈 값) / P@ssw0rd! | 입력 요청 안내 | 중 |
| TC-004 | 로그인 | 보안 | – | 따옴표가 든 아이디로 로그인 | ' or '1'='1 | 로그인 안 됨, 오류 화면 노출 없음 | 상 |
| TC-005 | 계정 잠금 | 경계값 | 가입된 계정 | 4회 틀린 뒤 올바르게 로그인 | 4회 실패 → 정답 | 로그인 됨 | 상 |
| TC-006 | 계정 잠금 | 경계값 | 가입된 계정 | 5회 틀림 | 5회 실패 | 계정 잠김 안내 | 상 |
| TC-007 | 사용자 목록 | 권한 | 관리자 계정 | 사용자 목록 화면 열기 | admin 계정 | 목록 표시 | 상 |
| TC-008 | 사용자 목록 | 권한 | 일반 계정 | 주소로 직접 접근 | test01 계정 | 접근 거부 | 중 |

**확인 필요**: 잠긴 계정은 언제 풀리나요(시간 경과 / 관리자 해제)? 비밀번호 길이 규칙이 있나요?
