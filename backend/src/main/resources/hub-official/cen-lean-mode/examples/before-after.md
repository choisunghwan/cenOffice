# 예시: 날짜 표시 기능

## 입력
"목록에 등록일을 '2026. 11. 25.' 형식으로 보여 줘"

## 줄이기 전 (흔한 과잉 구현)
- DateFormatter 클래스와 형식 설정 파일, 형식 옵션 5가지를 새로 만듦
- 날짜 라이브러리를 새로 설치

## 최소 구현
- 저장소에 이미 있는 `fmtDate()` 를 그대로 씀. 없으면 `Intl.DateTimeFormat('ko-KR')` 한 줄
- 새 파일·새 의존성 없음

## 작업 끝 알림
- 뺀 것: 형식 옵션(지금 쓰는 곳이 한 곳뿐)
- 재사용한 것: 기존 fmtDate()
