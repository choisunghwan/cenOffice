# 이 서비스에서 할 수 있는 일
질문: CEN OFFICE에서 뭘 할 수 있어요?
키워드: 기능, 할 수 있, 뭐해, 소개, 개요, 무엇, 서비스, 사용법

CEN OFFICE는 홈 입력창에 말로 시키면 일정, 회의, 도구, 화면 조작까지 처리해 주는 사내 AI 업무 공간입니다.
- 일정: 등록, 조회, 변경, 삭제, 회의실 예약 (예: "내일 오후 3시에 팀 회의 잡아줘")
- 회의: 화상 회의 시작·참여, 끝나면 회의록 만들기와 확정, 확정된 회의록 내려받기
- 도구: 업무를 대신해 주는 AI 도구를 찾아 쓰고, 직접 만들어 동료와 공유
- 결과물 양식: 한글·워드·엑셀·파워포인트 양식을 올려 두면 결과가 그 양식에 맞춰 나옴
- 화면 조작: 다크 모드, 사이드바, 새 채팅, 화면 이동도 말로 가능
- 대화 기록은 서버에 저장되어 다른 PC에서도 이어서 볼 수 있음
