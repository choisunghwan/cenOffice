# 심각도 기준

| 심각도 | 기준 | 예 |
|---|---|---|
| 높음 | 운영에서 데이터 손실·유출, 보안 사고, 장애로 바로 이어질 수 있음 | SQL 인젝션, 권한 확인 누락, 트랜잭션 없이 돈·재고 변경 |
| 중간 | 특정 조건에서 오동작하거나 성능이 크게 떨어짐 | null 미처리로 일부 요청 실패, N+1 조회, 자원 미반납 |
| 낮음 | 지금 문제는 없지만 나중에 실수를 부르기 쉬움 | 헷갈리는 이름, 중복 코드, 테스트 누락 |

## 머지 판단
- 높음이 하나라도 있으면: "다시 검토 필요"
- 중간만 있으면: "고친 뒤 머지"
- 낮음만 있거나 없으면: "그대로 머지 가능"
