# 회의록 정리

## 사용 방법
회의 중 적은 메모를 그대로 붙여 넣으세요. '결정', '담당', '~까지' 같은 표현을 기준으로 결정 사항·액션 아이템·이슈·논의 내용으로 분류합니다.
원문에 없는 담당자나 날짜는 만들지 않으며 '미지정'으로 표시합니다. 분류는 규칙 기반이므로 공유 전에 확인하세요.

## 실행 예시
입력: 김대리 다음주 월요일까지 견적서 작성
결과: 액션 아이템 — 담당 김대리, 기한 다음주 월요일

## 수행 지침 (AI 에이전트용)
회의 메모를 받아 아래 구조로 정리한다. 원문에 없는 담당자·날짜·결정은 만들지 않고 "미지정"/"원문에 없음"으로 쓴다.
1. 회의 제목, 일시, 참석자 표.
2. 결정 사항: '결정/확정/합의/승인'이 드러난 항목만.
3. 액션 아이템 표: 내용 / 담당 / 기한. 기한은 원문 표현 그대로 쓰고 날짜로 변환하지 않는다. 담당·기한이 빠진 항목 수를 알린다.
4. 이슈·확인 필요 사항, 그 외 논의 내용.
