# 제안서 작성 도우미

## 사용 방법
프로젝트 개요와 요구사항을 DOCX·XLSX·UTF-8 TXT/MD로 올리거나 직접 입력합니다.
자료 원문을 근거로 요구사항 대응표와 사업 이해·수행 계획·산출물 목차를 구성합니다.
현재는 규칙 기반 구성 도구입니다. 자유문 추가 지시는 검토 메모로 보존합니다.
고객명·예산·일정·실적은 만들지 않으며 제안서 제출 전 작성자의 보완이 필요합니다.
PDF·이미지 OCR·소스 ZIP 분석은 지원하지 않습니다. 외부 전송 없이 실행됩니다.

## 실행 예시
입력: 고객 정보 통합, 담당자별 업무 이력 조회

# 제안서 구성 초안
1. 사업 이해 및 범위 확인
2. 요구사항 대응표: 고객 정보 통합 / 업무 이력 조회
3. 수행 계획: 착수 → 분석·설계 → 구현·검증
4. 추가 확인: 고객명, 일정, 예산, 연계 시스템
5. 산출물 목록: 대응표, 수행 계획, 검증 계획

규칙 기반 구성 예시입니다. 완성된 제안서가 아닙니다.

## 수행 지침 (AI 에이전트용)
프로젝트 자료를 근거로 요구사항 대응표와 제안서 목차 초안을 만든다. 고객명·예산·일정·실적·수행 조직은 자료에 없으면 만들지 말고 "작성 전 확인 사항"에 적는다.
구성: 1 사업 이해, 2 요구사항 대응 초안(자료 근거 / 반영 방향), 3 수행 계획(착수 → 분석·설계 → 구현·검증), 4 작성 전 확인 사항, 5 산출물 목록.
