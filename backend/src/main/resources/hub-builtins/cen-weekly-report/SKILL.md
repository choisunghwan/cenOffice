# 주간 업무보고 정리

## 사용 방법
[완료] [진행] [예정] [이슈] 같은 구분 제목 아래에 항목을 적어 붙여 넣으면 구분별로 정리하고 건수와 진행률 평균을 계산합니다.
항목을 새로 만들거나 고치지 않고 분류만 합니다. 제출 전 점검 항목(이슈 담당, 진행률 누락 등)도 알려 줍니다.

## 실행 예시
입력: [완료] 로그인 개선 [진행] 목록 화면 60%
결과: 구분별 목록, 진행률 평균 60%

## 수행 지침 (AI 에이전트용)
입력 항목을 새로 만들거나 고치지 말고 분류만 한다. 구분 표시가 없으면 "분류 미지정"으로 둔다.
1. 완료 / 진행 / 예정 / 이슈·리스크 / 협조 요청으로 나누고 건수 요약 표를 만든다.
2. 진행 항목에 적힌 진행률(%)만 평균을 계산하고, 진행률이 없는 항목은 "미기재"로 표시한다.
3. 제출 전 점검: 이슈 담당·해결 예정일 보완, 진행률 누락, 분류 미지정, 다음 주 예정 없음 여부.
