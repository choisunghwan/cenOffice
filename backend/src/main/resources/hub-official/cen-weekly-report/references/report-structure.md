# 보고서 구분

| 구분 | 들어갈 내용 | 판단 기준 |
|---|---|---|
| 한 줄 요약 | 이번 주 가장 중요한 결과 1~2개 | 보고받는 사람이 이것만 읽어도 되게 |
| 완료 | 이번 주에 끝낸 일 | "완료, 배포, 반영, 끝냄, 마감" 등 끝난 표현 |
| 진행 중 | 이번 주에 하고 있고 다음 주에도 이어지는 일 | 진행률(%)이나 "진행, 개발 중, 작성 중" |
| 다음 주 예정 | 아직 시작 안 한 다음 주 일 | "예정, 다음 주, 할 일" |
| 이슈·리스크 | 일정 지연·장애·결정 대기 등 | "지연, 문제, 장애, 미정, 확인 필요" |
| 협조 요청 | 다른 팀·사람에게 필요한 도움 | "요청, 필요, 부탁, 대기" |

- 같은 일이 두 구분에 걸치면(예: 일부 완료) 더 진행된 쪽에 넣고 남은 부분을 괄호로 적는다.
- 프로젝트가 여러 개면 구분 안에서 프로젝트별로 묶는다.
- 진행 중 항목에 진행률이 있으면 평균이 아니라 항목마다 그대로 적는다.
