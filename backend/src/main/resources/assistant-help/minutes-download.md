# 홈에서 회의록 다운로드
질문: 회의록을 홈에서 바로 받을 수 있어요?
키워드: 회의록, 다운로드, 받아, 내려받기, 홈, 입력창, 어제, 지난주

홈 입력창에 "주간 팀 회의 회의록 다운로드해줘", "지난주 회의록 워드로 받아줘"처럼 말하면 됩니다.
- 내가 참여한 회의의 확정된 회의록만 찾습니다. 초안은 받을 수 없습니다.
- 어떤 회의록인지 정하지 못하면 최근 확정된 회의록을 카드로 보여 주고 고르게 합니다.
- 카드에서 형식(자동/한글/워드/엑셀/파워포인트/PDF)을 고르고 "받기"를 누릅니다. 자동은 내 양식 → 공용 양식 → 양식 없이 받기 순입니다.
- 양식에서 근거를 못 찾은 항목은 채팅에서 채우지 않고 "비어 있는 항목"으로 알려 줍니다.
