# 회의록 내보내기와 양식으로 받기
질문: 회의록을 우리 양식으로 받으려면요?
키워드: 회의록, 내보내기, 양식, 내 양식, 공용 양식, 양식 없이 받기, 다운로드, 한글, 워드, 엑셀, 파워포인트, PDF

확정된 회의록 화면 아래 "회의록 내보내기" 카드에서 탭으로 고릅니다.
- 내 양식: 내가 직접 올린 회의록 양식에 맞춰 받습니다. 나만 볼 수 있습니다.
- 공용 양식: 관리자가 "회의록 정리" 도구에 올려 둔 공통 양식에 맞춰 받습니다.
- 양식 없이 받기: 시스템이 만든 기본 문서(한글, 워드, 엑셀, 파워포인트, PDF)로 바로 받습니다.
- ＋ 내 양식 올리기: 한글·워드·엑셀·파워포인트 아이콘으로 내 양식을 올리고 바꾸고 지웁니다.
양식으로 받을 때는 미리보기를 보고, 비어 있는 항목은 직접 쓰거나 선택지를 고른 뒤 받습니다. 회의록에서 못 찾은 항목은 지어내지 않고 비워 둡니다. 쓸 양식은 내 양식 → 공용 양식 → 양식 없이 받기 순으로 정해집니다.
